# @patina/help-system

In-context help and guidance infrastructure for the Patina platform. Implements a four-layer architecture (Ambient → Reactive → Proactive → Reference) that surfaces help where questions form, without interrupting the work users came to do. All guidance copy lives in Sanity CMS and is fetched by surface key — nothing is hardcoded in components.

See [`docs/prds/Guide/patina-help-guidance-engineering-handoff.md`](../../docs/prds/Guide/patina-help-guidance-engineering-handoff.md) for the full specification and [`/Users/kody/.claude/plans/review-the-documenation-for-compressed-shore.md`](../../.claude/plans/review-the-documenation-for-compressed-shore.md) for the master implementation plan.
