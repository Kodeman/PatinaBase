Adds the service-acceptance request email renderer for designer-approved outbound drafts, with the client `/acceptance/<requestId>` link. SQL remains the sole owner of the sent transition.

Adds JWT-verified `service-acceptance-paper-hash`. The caller's studio projection must contain the intake before a service client is created. Native Storage listing is limited to 20 pages of 100 objects in the project folder; a missing object (including beyond that bound) returns `paper_document_not_found` (404). Object id, version and eTag must match the recorded intake both before and after hashing the downloaded bytes. The stamp RPC remains authoritative; revoked permission or inactive scope capability returns `service_acceptance_inactive` (403). No grant, activation or migration is included.

Not deployed. At ship time deploy `service-acceptance-paper-hash` and redeploy every importer of the changed shared modules, including transitive importers.
