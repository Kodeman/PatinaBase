# leah-photos

Drop the photographs here — one file per shot, any names you like.

`catalog-manifest.csv` and `editorial-manifest.csv` point at them by path:
`leah-photos/oak-table-01.jpg`.

**1600 px on the long edge, JPEG quality 80.** To resize everything in this folder on a Mac:

```
sips -Z 1600 leah-photos/*.jpg
```

This folder is named in Kody's upload step, so please keep the name.
