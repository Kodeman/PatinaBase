## Simulator rules (proven in prior programs — violating them manufactures fake defects)
1. NEVER install a build made with CODE_SIGNING_ALLOWED=NO for a walk (it strips entitlements; the keychain rejects every call; sessions never persist; writes silently no-op). The steward's signed Debug build is the only install.
2. Explicit udid on EVERY blitz and simctl call. Never "booted".
3. HID preflight before trusting any input: scan_ui, tap a known control, screenshot, confirm the screen changed. Headless-booted simulators swallow synthetic input while screenshots look healthy.
4. Wait at least 250 ms after any layout-changing action (1 s after navigation) before the next tap; never batch taps across a layout change.
5. Screenshots ONLY via "xcrun simctl io <udid> screenshot <path>" or mcp__blitz-iphone__get_screenshot. NEVER desktop screencapture. Read every PNG after taking it and confirm it shows what you think.
6. The simulator keychain survives app uninstall. Fresh-install state = the steward's erased clone; to reset mid-walk: terminate, uninstall, "xcrun simctl keychain <udid> reset", reinstall. "--resetonboarding" resets onboarding flags only.
7. Blitz tools (load with ToolSearch "select:mcp__blitz-iphone__scan_ui,mcp__blitz-iphone__describe_screen,mcp__blitz-iphone__device_action,mcp__blitz-iphone__get_screenshot,mcp__blitz-iphone__launch_app"): scan_ui {udid, region:"full", query?} returns frames in logical points; describe_screen {udid} = full AX tree incl. static text; device_action {udid, action:"tap"|"input-text"|"swipe"|"button", params:{x,y}|{text}|{fromX,fromY,toX,toY,duration}|{button:"HOME"}}. Views carry stable AXUniqueIds (auth.welcome.guestButton, auth.form.emailField, DailyRoomView.BellButton, companion.intro.later, ...). Scan first, tap the frame centre; never guess coordinates from a screenshot.
8. Device settings: "xcrun simctl status_bar <udid> override --time 9:41 --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4"; "xcrun simctl ui <udid> appearance light|dark"; Dynamic Type: "xcrun simctl ui <udid> content_size <size>" where size is one of extra-small, small, medium, large, extra-large, extra-extra-large, extra-extra-extra-large, accessibility-medium, accessibility-large, accessibility-extra-large, accessibility-extra-extra-large, accessibility-extra-extra-extra-large. Deep links: "xcrun simctl openurl <udid> <url>". App logs: xcrun simctl spawn <udid> log show --last 3m --predicate 'process == "Patina"' --style compact.
9. Relaunch = "xcrun simctl terminate <udid> cloud.patina.app" then "xcrun simctl launch <udid> cloud.patina.app <args>". Cold-launch timing: note the launch time and screenshot at 0.5 s intervals until the first interactive frame.
10. If a tap does not land after 3 attempts with settle, record it (finding or coverage gap) and move on. Never loop.
