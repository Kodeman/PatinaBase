LIMITS

This deck does not claim user research, measured outcomes, or a built product.

  • No user research was run — no designer was observed, interviewed or surveyed.
  • Every seat in the panel is a simulated seat.
  • The evidence is local dev seed data — the rich document carries 3 FF&E lines and 0 rooms, so any finding that depends on a long schedule is thinner here than it would be on a real sixty-line one.
  • The mockup is a stylesheet and a script over the invented Vandersteen specimen, not the product.
  • The frame-budget figures in the proposal are design targets, not measured outcomes.
  • Nothing here is built, and no product code was changed.
