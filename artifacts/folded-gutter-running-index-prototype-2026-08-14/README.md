# Folded Gutter × Running Index

High-fidelity responsive interaction prototype for Patina's Document page.

- **≥1440px:** 56px resting gutter; open Sections with the visible tab or `g` then `s`. The local index overlays the paper without reflow. Pin is scoped to the browser tab.
- **1180–1439px:** current 56px compact lifecycle rail.
- **<1180px:** current bottom-bar grammar with a modal Sections sheet.

Open `bundle.html` for the self-contained review build, or run `corepack pnpm dev --host 0.0.0.0` for development.
