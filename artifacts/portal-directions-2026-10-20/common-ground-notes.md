# Common Ground

A relationship and decision record: the studio, homeowner, and workshop see the same agreed direction, with only the context each needs.

## Visual plan

- Forest `#244C3D`: shared agreement and primary actions.
- Mineral `#EAF0EB`: quiet page ground and shared sheets.
- White `#FFFFFF`: working space.
- Ink `#20362C`: readable text.
- Moss `#66796C`: secondary text.
- Brass `#A78244`: the current point on the project spine, never a warning/status color.

Typography uses the locally available humanist sans Avenir Next, Segoe UI, then Trebuchet MS. Broad, sentence-case statements make the current agreement feel human; compact supporting text keeps working details easy to scan. No font download is required.

The layout is left aligned. A green agreement panel holds the stable project context; a continuous vertical spine on white connects what was agreed, what needs a choice, and what follows. The furniture stays present as a modest visual reference. On mobile these become a single reading sequence.

```
Presentation controls / role preview
Studio / project / people
┌──────────────────┬──────────────────────────────┐
│ Shared direction │ One clear next step          │
│ human statement  │ ● Agreed                     │
│ room photograph  │ │                            │
│ project context  │ ◉ Finish decision + chair    │
│                  │ │ Open two-sided sheet       │
│                  │ ○ Workshop → installation   │
└──────────────────┴──────────────────────────────┘
```

The memorable element is the shared project spine. It records an actual sequence, rather than decorating a dashboard. The plan deliberately avoids the familiar warm-cream/serif direction, task grids, and activity feeds. Green is a permanent structural color, not a success status.

## Business fit

Middle West Studio remains the author and steward of the engagement. A first studio hire can read the agreed direction before acting. Nora sees a focused finish choice and the shared record; Northline Workshop sees its brief and the studio's pending release. Studio notes are never rendered in the client or maker preview. Outbound workshop communication stays a draft requiring designer review.

## Demonstrated interactions

- Switch Designer, Client, and Maker role previews; the actual visible information and actions change.
- Open the finish sheet, compare natural and smoked oak, and record a sample selection locally.
- Read private/shared layers together in the designer sheet; the client sees only the shared sheet.
- Expand the agreement history before or after a choice.
- Preview and save a workshop draft locally; nothing sends externally.
- Reset the sample, close dialogs with Escape, and use keyboard focus throughout.

The prototype keeps its state in the browser session. It uses fictional project data and illustrative photography; it is not a production portal. All displayed selections and saved drafts are simulations.

## Founder choice

Choose Common Ground if the most important question is, “Do we all understand what we agreed?” It makes trust and handoff visible without turning the project into a chat feed.

Tradeoff: this direction gives a single project depth and calm. A studio handling many parallel projects would need a quiet cross-project entry surface; that is intentionally outside this mockup.
