# Workroom

The project is a room you can work on. Furniture, materials, specifications, and the next decision sit in one spatial record. This direction makes the designer’s visual judgment the center of the product.

## Design plan

- Paper `#FCFCF8`; white `#FFFFFF`; blueprint `#EAF0FB`; cobalt `#214DCB`; ink `#17243B`; technical rules `#C9D3E5`. Warmth comes from the materials, not the application chrome.
- Arial / Helvetica throughout. Large, close-set, medium-weight project title; compact body; small technical annotations. A deliberate departure from the existing Patina deck typography, authorized by the fresh-design brief.
- Desktop: project identity over a two-column workspace. A broad room collage owns the left; the selected piece’s inspector owns the right. A small room plan anchors the spatial context. Decision history runs below both.
- Mobile: preserve the complete composition, then put the inspector beneath it. Role controls remain visible. No hidden horizontal canvas or drag-only controls.

```text
Project name                                      Place / Install
┌────────────────────────────────┬─────────────────────────┐
│ Living room                    │ Selected piece          │
│                                │ Chair specification     │
│    room photo      chair       │                         │
│                                │ Finish choice           │
│       material     samples     │ Save / Draft            │
│ plan + designer direction      │                         │
└────────────────────────────────┴─────────────────────────┘
Decision record                           Next step
```

The initial plan was reviewed against the brief: the defining element is a tangible, asymmetric room composition rather than a dashboard of cards. The cobalt selection frame communicates the current object, and the blueprint grid gives the work surface a drafting context. No decorative statistics or marketing hero.

## Business fit

- Designer: a first assistant can understand the room, current specification, and remaining client decision without a separate handoff.
- Client: Nora sees Leah’s direction alongside a single finish choice. The chair is already part of the room, not an item in a shopping catalog.
- Maker: Northline sees the specification and the hold for finish approval. A preference is never treated as a release to production.
- Commercial purpose: keep the selected piece connected to designer judgment, client agreement, and maker execution so furniture procurement stays within the engagement.

## Interactions

- Designer, Client, and Maker render substantially different content around the same project record.
- Select the chair or linen in the composition to change the specification inspector.
- Select natural or smoked oak, then save a local sample preference. The visible decision record updates and persists on this device when storage is available.
- Open the room and dimension sheet from each role; close with the explicit button, Escape, or outside click.
- Write and save a local draft note; no external message or order is sent. The room record acknowledges the draft.
- Keyboard focus styles, native dialog focus management, responsive layout, reduced-motion support.

## Tradeoff and founder decision

The room board makes visual choices and delegation easy to grasp. Long projects with many pieces could become visually dense, and deep contractual history deserves a more text-led treatment. The direction should be chosen if founders believe that understanding the room is the fastest route to understanding the engagement.

**Founder question:** Should a designer open Patina into the room she is shaping, with the written record attached to it?
