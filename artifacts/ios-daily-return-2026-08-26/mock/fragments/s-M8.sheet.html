s-M8 · Home Screen widgets · screen sheet
PurposeGive a person a reason to come back without asking them to open anything: a small and a medium widget that carry the record of what moved since they were last here.
Entry pointsThe iOS widget gallery. Tapping either opens the app; the deck draws the Home Screen, not the gallery.
ComponentsNew: one WidgetKit extension serving both families (and the Lock Screen rectangular on s-M7) — an App Group entitlement, its own bundle id under the existing ASC app, and a timeline provider. Existing: the badge refresh that already computes the counts this snapshot is written from.
CopyEyebrow “SINCE THU” · “Leah sent a proposal” / “Tue” · “Leah asked about the rug colour” / “Aug 22” · small: “Leah sent a proposal” / “Tuesday”. Empty: “Nothing moved since Thursday.” (B) or “NOTHING NEEDS YOU” over the room (A). Signed out: the wordmark and the mark, nothing else. The weekday labels are example dates; the rug decision’s Aug 22 is the seed’s.
DataAn App Group snapshot written on app foreground — the same queue the Studio and the bell read (BadgeCountService, StudioQueueBuilder). No network call from the extension. A delivered push does not run app code and adding content-available would change the payload for every existing apns-send caller, so the widget is allowed to be one open behind by design.
StatesNothing moved — the empty line, never a zero and never a count. Signed out — the wordmark. No data yet — “Open Patina to see your house.” Stale — the eyebrow always names the window it is describing, so an old snapshot reads as a date rather than as a lie.
InteractionsTap → the app (patina://), landing on Today. Analytics: widget_tapped / widget_opened — new.
TierThe widget renders only for a signed-in account. At discovering it can still carry a room and a save; the money and designer lines belong to engaged and above.
Callouts1 · the eyebrow dates the window — “since Thursday”, not “4 items”. 2 · two rows of what moved, each with its own date; both directions forbid a running tally of chores on this surface. 3 · the small family carries the same top line and nothing more. 4 · the extension itself is the cost: the app has three targets and no extension today, so this is a bundle id, an App Group and an engineer-week, not a free win.
New vs todayAll of it. There is no widget, no extension target and no App Group in the project.
