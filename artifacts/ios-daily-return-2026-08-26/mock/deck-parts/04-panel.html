How nine reviews became one verified list

  • Walk. Nine seats ran the task script against a 155-shot Simulator walk (iPhone 17 Pro, iOS 26.5, guest and signed-in client, main 3cd84ecb3), plus code-read grounding where the Simulator can’t reach — camera, LiDAR, AR.
  • Findings. Each seat filed its own findings in its own words. Collating them on disk produced 213 distinct claims.
  • Three refuters. Every claim was checked three separate ways before any of it reached this deck — against the app’s own code (code-truth), against ruled canon (canon-truth), and by reproducing it on the booted Simulator (repro).
  • What survived. 199 verified outright, 14 held as contested (both sides’ evidence kept, confidence lowered), 0 unverified, 0 dropped.
