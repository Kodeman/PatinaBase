What a homeowner opens, before either direction touches it

The same four blocks, in the same order, at every tier — including a guest who has never signed in.

The Daily Room mounts a greeting, one Next Move card, one editorial story and one Active Room card. Nothing else. There is no tab bar and no nav bar (ruled R29) — the only way anywhere else in the app is the Companion orb, which appends the same Home / Profile / Sign‑in tail to whatever six rows it is showing.

The Studio — projects, proposals, invoices, decisions, messages — lives two acts below this screen: the monogram opens Profile, and Profile opens StudioHubView. Three engagement tiers resolve underneath all of it — discovering, engaged, activeProject — and the home reads none of them.
