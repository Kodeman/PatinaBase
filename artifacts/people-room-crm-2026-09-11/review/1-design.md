# Design review: the People room specimens

Reviewed against `synthesis/direction.md` (§1, §3, §3.8, §3.9, §5) and `specimens/SPEC.md` (§5 acceptance, §6 width rules, §8 forbidden), the two HTML specimens, and all twelve plates in `shots/`.

Method: read both direction/SPEC docs in full; read both HTML files in full; viewed all twelve PNG plates (including pixel-level crops to verify word-pigment colour, not just visual impression); ran targeted `grep`/`python3` checks for forbidden strings, hex literals, `disabled`/`placeholder=`/`box-shadow`/`text-overflow`, brace balance in the pasted token block, and a systematic extraction of all 131 double-quoted acceptance strings from SPEC §5 checked against both files (cross-verified against screenshots, since many are built by JS template concatenation rather than appearing as literal source substrings — confirmed present on the rendered face in every such case).

## Result

**clean: false** — 1 blocking finding (exact-acceptance-string / cross-width fidelity failure), plus major/minor findings below.

## What held up (verified, not just spot-checked)

- **Every acceptance string checked** across all six states at both widths, including the ~40 that are built by JS template concatenation rather than appearing as literal HTML source (verified against the rendered PNGs, not just source grep): directory chip order/labels/`aria-pressed`, Dana/Pete/Frank/Ray/Joe row content, firm rows, duplicate band, person card R1–R6, company card R1–R6 including the 4-row paper table, roster head/vitals/bands/site-access line/unfold, add-sheet fields/consequence/terminal, site-access card regions in the exact §6.2 order (call first → way in → key holder → hours → receiving → who was told).
- **Fixture facts**: Dana Kowalski text-only rule with the dead/bounced email (`dana@northgateelectric.com`, "This address bounced back, 12 March 2026...") — present, exact, both widths. Pete Rusk "Opted out by text, 3 December 2025, on the Lindqvist kitchen." — present, exact. Northgate Electric COI "Lapsed" 31 Mar 2026 blocking site access/payment/draw — present in both the company-card paper table and the roster's held clause on Dana's row, exact wording, correct terracotta leading rule. Chidi Okonkwo "Signs money to $2,500." (Call Sheet authority, plain uncoloured text, not a `.word`) and his separate contact-rule sentence "Email first. Call for anything over $2,500." — both present and correctly distinguished. Ngozi Eze "holds a key" / key holder line — present. Luis Ochoa "controls the gate" — present. "The code is held off Patina; ask Luis Ochoa." — present verbatim, no code digit anywhere in either file (`grep` for the literal lockbox/gate code found none).
- **The four word families and pigment**: `TONE`/`WORD_PIGMENT` maps in both files match SPEC §3.8 exactly (Reach: Account/Field link/On paper → current/pending/dormant; Consent: Texting/Invited/Opted out/Not asked → current/pending/blocked/dormant; Stage: On the job/Awarded → current/pending, all others dormant; Paper: Current/Lapses in 30 days/Lapsed/Not on file → current/pending/blocked/dormant). Verified at the pixel level (2× crop of the directory word columns) that colour and label always co-occur — no word renders as colour alone, and the sage/golden/terracotta/dormant hues are visually distinct once zoomed (they read close to grey at thumbnail scale but are genuinely different hues). Authority (`.word--plain` / `.row-rule`, transparent border, `ink-subtle`/`ink` text, no uppercase, no letter-spacing) never uses the bordered `.word` treatment on either file — "No authority on this job", "Signs money to $2,500.", "Approves fee changes.", "Prepares only.", "Controls the gate.", "Holds a key." all print as plain text.
- **Marrow & Sons reads `Current`** in the Directory (`#state-directory`), and `#state-company` opens Northgate Electric with `Lapsed`, matching SPEC §3.9 C8's fixture-overrides-brief resolution.
- **No forbidden vocabulary** on either face: no `AI`, `CRM` (only the `.crm-*` CSS class names, never rendered text), `dashboard`, `wizard`, `badge`, `pill`, `chip` (only a CSS comment "Chips and lens words" in 390, not rendered), `modal`, `toast`, `spinner`; no `specimen`/`prototype`/`example`/`fictional`/`Lorem`/`TBD`/`sample` anywhere except the state bar (both required occurrences of "specimen"/"invented" sit only in the `.bar`, plus the mandated trailing `<!-- specimen-complete -->` comment and one CSS comment, neither of which is visible page content); no schema words (`client_rep`, `party_kind`, `sms_consent_status`, `studio_contact_id`, `project_parties`, `PD-n`, `CRM-n`, `G-n`, `E1`–`E15`) — every `F-nn` occurrence found is inside the `<script>` fixture/lookup data or a `data-person="F-11"` attribute, never rendered visible text.
- **`box-shadow`, `text-overflow`, `placeholder=`, and a literal `disabled` attribute** all return zero matches in both files (the one `disabled`-substring hit in each is `[aria-disabled="true"]` in the shared CSS, which is required, not forbidden). No hex literal appears outside the pasted token block (lines 16–89) in either file.
- **Structure**: both files end with exactly `<!-- specimen-complete -->` as the last line; `Remove` appears nowhere, "Close this seat" is used throughout.
- **Width fidelity (§6)**: 1440 shows four bordered `.word` columns per row (reach/consent/stage/paper) at the Directory, two on the Call Sheet (reach/stage); 390 shows reach as plain inline text on the row with the other three words moved inside the seats/unfold disclosure (and pre-opens exactly the rows — Dana, Joe, Pete, Frank, Ray — whose acceptance criteria require a word or clause that only exists inside that disclosure, a sound accommodation for the render tool's no-click, hash-only navigation). Tables convert to label-over-value stacks at 390 with no sideways scroll. `document.documentElement.scrollWidth`/`clientWidth` overflow flag is `false` for all six 390 captures per `people-room-console.json` (see DR-2 for the 1440 half), and manual review of all six 1440 plates shows no visible overflow.
