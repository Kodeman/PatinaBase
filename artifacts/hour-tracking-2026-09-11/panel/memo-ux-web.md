# Memo — UX_WEB (Web interaction designer, designer portal)

## 1 · Seat and stance

I am the web interaction designer for the designer portal — The Document's grammar (paper, drawer, sheets, ⌘K, no tabs). I optimise for the fastest correct log from wherever the cursor already is, and for edits that don't need a page. I distrust modals, new routes, and anything that pulls the eye off the work (R69) — including a naive "four views" build that turns into a dashboard.

## 4 · The four views

| View | Where it lives | Who sees | What it shows | What it is NOT |
|---|---|---|---|---|
| Mine | The existing Hours ledger sheet (D9/R77) — default, no lens shown/needed | Every studio member, own rows only | Week paging, day groups, entry rows (project · activity · duration · rate · billing state), today/week totals, all-time unbilled balance, Bill it / Export week | Not a dashboard — no charts, no gauges beyond the existing mono billable-% readout; no tab bar |

| Studio | Same Hours ledger sheet, scope lens set to "the studio" | Owner/admin only | A `studio_hours_rollup`-backed grouped ledger (by member or by project), still rows not tiles — the existing week-total/billable-% readout generalized | Never a bar-chart/pie-chart dashboard (Vision §6); never a persistent nav item — reached the same way as any other ledger (⌘K / `g h` / the drawer) |
