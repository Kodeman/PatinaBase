## 3 · Observer strategy

Two observers, because they answer two questions with two geometries: **where is she** (the reading band, centre-weighted) and **what must exist ahead of her** (the lookahead, bottom-weighted). One observer with two root margins is impossible; one observer resolving both is the ambiguity F105 measured clean today.

**Index observer** — `hooks/use-document-running-index.ts`: `rootMargin: '-20% 0px -62% 0px'`, `threshold: 0`, unchanged; `resolve()` unchanged; `JUMP_LOCK_MS = 700` unchanged. Attach: replace `:117-133` with `new MutationObserver(attach)` observing `[data-document-paper]` `{ childList: true, subtree: true }`, calling `observer.observe` for any unattached root (idempotent), disconnecting on cleanup. `lock` gains `mountThrough` (Wave 4): before `scrollToRegion`, `useLensDensity` exposes `forceFullThrough(key)`.

**Density observer** — `hooks/use-lens-density.ts`:
```ts
export interface LensDensityApi { forceFullThrough(key: DocumentIndexKey): void; settled(): Promise<true>; subscribe(region, cb): () => void; getDensity(region): RegionDensity | null; freeze(frozen: boolean): void }  // D-B15/D-B19
export function useLensDensity(paperRef: RefObject<HTMLElement>): LensDensityApi
```
One `IntersectionObserver` for all roots: `{ root: null, rootMargin: `0px 0px ${LENS_LOOKAHEAD_PX}px 0px`, threshold: 0 }`. Entry `isIntersecting` → mark `pending`.
