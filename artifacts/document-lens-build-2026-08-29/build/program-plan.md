# The Smart Lens → production (build program)

## Context

The Document's "smart lens" proposal (deck 932d66c0…, mockup 65b060ad…) is ratified. This program builds it into the designer portal and ships it to app.patina.cloud. It replaces the job ticket with a 56px declared-height lens band, turns the spine into a ladder of the paper's own stops, lets regions open ahead of the reader in one direction, gives pre-work spreads real regions, and sets one region-spacing token — eleven mechanics (L-1…L-11), six waves, R127/I152 in `docs/design/the-document/DECISIONS.md`.

**Rulings taken in the interview (Kody, 2026-08-29):**
1. **R127 = the proposal as written** (`artifacts/document-lens-proposal-2026-08-28/source/proposal.md`). Engineering deviates only where real data contradicts the mockup; every deviation logged (`build/design/deviations.md`) and carried into I152.
2. **All six waves, one production deploy at the end.** Rollback = `wrangler rollback 9c0c2cdd-2041-4848-a193-93d9e8fb0b71` (the version live now) or a revert of the single merge.
3. **No feature flag — GA.** Every "flag off restores…" line in proposal §9 is void; replacement law: **the tree is shippable at every wave merge** (gates green, walk clean, `desk-walkthrough.spec.ts` green).
4. **Two Fable seats** (`subagent_type: fork`): ARCHITECT (technical design; rules engineering deviations) and DESIGN LEAD (mockup as visual target; rules what prints; final visual walk). Both review, neither implements.
5. **Precedence when mockup and proposal disagree:** proposal governs MECHANICS (one-direction density, fold→density, no seam var, declared 56px); mockup governs WHAT PRINTS (yielded segments print their name, L-6 partial yield, 1280 collapse form, foot reserve). Design lead writes the reconciliation in Wave 0.
6. **Seed:** hand-run `scripts/the-document-lens-seed.sql` (idempotent, deterministic ids) — ≥4 rooms, ≥60 FF&E lines with `product_id` links, POs, one damage, one overdue approval. Not wired into `config.toml`. *(My call: the long paper is a NEW fixed project `b0000000-0000-0000-0000-0000000000d5` "Aspen Loft — the long paper" rather than growing `…d1`, because `…d1` is pinned by four e2e surfaces and six seed files; growing it would make Wave-1 failures ambiguous.)*
7. **Acceptance:** agents walk every wave; Kody walks **prod after deploy** (rollback if wrong). No Kody session before ship.
8. **Debts:** Wave 0 fixes the e2e baseline (9 failures → 0, quarantine only truly environmental with a written reason); aged-oak / reduced-motion offenders fixed only on files the lens rewrites; F24 and I114 out.
9. **Freeze:** `components/document/**`, `app/(document)/doc/[id]/**`, `lib/document/**`, `hooks/use-document-running-index.ts`, `src/app/globals.css` are frozen on `main` for the program; exceptions land only at wave boundaries (integration rebases, anchors re-verified, gates re-run).

**Verified on `main@dab057537`:** every `path:line` in proposal §9 resolves (±1–5 drift); jest 458 suites / 5170 tests, type-check 0, lint 2 known errors; e2e 15 document specs with 9 pre-existing failures; agents are hook-blocked from `infra/deploy-portal.sh`/`wrangler deploy` (`scripts/hooks/core.mjs`) — Kody runs the deploy script; `deploy-production.yml` cannot pass (`integration.yml` red 3 days); no `browserslist`; no seed has rooms+lines together (max 3 lines on any project; `…d1` has 2 rooms, 0 lines); five unmerged branches carry big Document diffs; next ledger ids R127 / I152, headings `### <ID> · <title> — <date>`, deploys as `I152-deploy`.
