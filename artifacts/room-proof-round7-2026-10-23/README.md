## Review route

1. Start with **Full service with a building team**. Try the other three service arrangements.
2. Change the purchasing route, package exception, drawing development or appointments. Preview the arrangement on the job.
3. Inspect **pricing, maker return, pre-fabrication, post-issue change and site** moments. These are presentation comparisons, not live actions.
4. Compare the **craftsman, hardware supplier, GC and electrician** work copies.
5. Inspect **client acceptance**: waiting, no response, returned item, one client pending, linked maker acceptance, accepted with an obligation, and eligible service completion.
6. Record and download founder feedback at the end of the paper.
