Before this can go: notes for the review

A pre-flight list above the act, there before anyone presses anything. Each row names one hold, and its fix act opens the fix in a drawer inside that row, so Leah never leaves the composer. When a hold is fixed, its row turns to Done and says what was done. The act stays held (§A5) until the list is clear.

Try it

  • Read the list above Draft the invoice. Press Link a client in the first row and pick the household. The row turns to Done, and focus moves to the next row's fix.
  • Set the prices opens both pieces in one drawer. Price each one, or leave both off this invoice. Each saves on its own; Enter in a field saves it.
  • Press the held act at any time. Focus lands on the first open row's fix and the status line says why.
  • Case 3 adds a row no one here can fix. It says Ask the owner and offers no act, so there is never a dead button.

How it meets the house rules

  • §A5 and §A6. The act is aria-disabled, it lands on activation, and the consequence sentence still sits directly above it, in every state, naming the holds.
  • "Ticks itself off" without a tick. §G-11 rules out the ✓ glyph and green fills, so state is a word in the first column: To do (terracotta-ink, §G-13), Done (ink-subtle) or Ask the owner. The row's sentence changes to the result: "Linked to The Kuehns".
  • D4. Rows are hairlines. The drawer is a paper-lift face with a 2px oak rule on its leading edge, the note-edge idiom. There are no shadows.
  • Drawers. Each fix act carries aria-expanded and aria-controls. Esc closes an open drawer and returns focus to its act.

What it reuses

The readiness precedent in rooms/drafting/agreement/readiness.ts (blockers, partsNeedingAttention, blockersForPart). An invoiceReadiness() pure function would feed this list, canDraft and the consequence sentence from one place, and would make the throw at use-invoices.ts:770 unreachable from the composer. The client drawer would be ClientPicker + useAttachDocumentClient (RPC set_document_client), the same write the household sheet already makes.

Risks

  • It adds a block to a sheet that is already long. With a single hold, the list is a heavy frame for one line; it could collapse into the consequence sentence plus one inline act.
  • The same hold can be fixed in two places, the row and the region. Both write the same state here, and they must stay one write in the product.
  • The list sits near the act and far from the pieces it names. The drawer brings the fix to the list, so the pieces region only shows the result.
