## What's already excellent (protect this)

1. **Clean seam.** The canvas owns transient gesture/view state only and emits one semantic commit per gesture; it imports no persistence, fetching or auth (BoardRoomCanvas.tsx:533-537). Rare discipline for an in-house canvas.
2. **The command engine is genuinely good.** No-op fingerprint rejection (:143), stale-id rejection before history or any buffer (:137), 500ms same-id coalescing (:161-180), 100-step depth, and — the standout — `revertFailedStructuralTransition`, a three-way inverse that rolls back only the failed write's fields and preserves later unrelated edits (controller:436-505), plus `historyAfterStructuralFailure` keeping the unaffected history prefix instead of nuking undo (:377-424).
3. **Smart guides carry both alignment and equal-spacing cases**, at a screen-constant 6px tolerance, drawn at 1/zoom so they stay hairlines at any zoom (:2023-2066).
4. **Group resize** scales proportionally about the anchored corner with a per-item 40px floor and a uniform-scale path for corner handles (:456-518) — the hard case, done right.
5. **Section membership** is derived from centre-in-band at drop and committed under the *same gesture id* as the move, so it's one undo step (:1277-1304 + controller:1435-1439).
6. **Keyboard nudge** respects locks, does 1px/10px, coalesces by direction key, and adopts the DOM-focused item when it isn't selected (:1534-1591).
7. **Touch long-press context menu** with an 8px move tolerance and 1s click/contextmenu suppression windows (:756-791, :1676-1681) — carefully built.
8. **Context menu** has roving arrow/Home/End focus and 44px rows (controller:1621-1663).
9. **Canvas auto-grow compensates the pan** so left/top growth never jumps the view (`offsetViewForStateTranslation`, :667-678) — and it compensates again on rollback.
10. **Inspector fields commit on blur/Enter** with a focus-safe draft resync, so an in-flight edit survives a concurrent geometry save and no keystroke becomes an undo step (board-room-inspector.tsx:118-165).
11. **Alt-drag ghost renders the real item**, not a rectangle (:1940-1975).
12. **Reduced motion** is honoured on the view transform, and marquee correctly excludes locked pins.

## Two synthesis notes

- **The most valuable P1 is CI-05/CI-02, not a gesture.** The gesture layer is above class average; what fails is the *project-owned* save leg and the shell's suppression of controls the canvas already ships. Both are small fixes with large hand-feel returns.
- **Waivers predicted the prod failures.** AC1.11 waived "an explicit persisted multi-drag delta assertion" → F2; AC1.6 waived the real-gesture pass → CI-01/CI-07. The waived rows are not noise; they are the defect map.
