# Mood Board UX Audit — Visual/UI Design Lens

Findings tagged after reading `06-acceptance-evidence.md` + `README.md`. Format: `ID | severity | confidence | area | claim | evidence | suggested direction`.

## Findings

VD18 | P3 | Low | Coherence | The on-canvas note editor uses a distinct warm-parchment palette (unique in the room) while every other chrome element uses neutral tokens — an unexplained one-off material treatment. | `board-room-shell.tsx:165-167` (`#F3E9D5`/`#E0D2B8`/`#4A4137`) vs. the rest of the file's `var(--bg-surface)`/`var(--border-default)` usage. ## What's already excellent
- `BoardCoverArt`'s fallback ladder (generated cover → 4-up mosaic → heading-italic monogram) is thoughtful and on-brand typographically.
- The multi-select inspector (Align/Distribute/Section/Lock, disabled-until-3 distribute) is a genuinely rich, well-organized panel for this tool's maturity.
- Add-rail's per-owner adaptation (project-only "In project" tab, proposal-only palettes/feedback with explanatory copy rather than silent absence) shows real information-architecture care.
- Export dialog's three destination cards use plain-English, jargon-free one-liners at the decision point — the feedback-*after* export is the weak link (VD4/VD15), not the choice itself.
- Share dialog is the best-designed dialog in the set: label + expiry + one-time-reveal link, select-on-focus, explicit "only a hash is stored" security note — proof the right patterns already exist in the codebase (VD5's fix is copy-paste from here).
- Consistent 44px (`min-h-11 min-w-11`) touch targets and `focus-visible` outlines across nearly every interactive element — unusually strong accessibility discipline for a canvas-heavy surface.
