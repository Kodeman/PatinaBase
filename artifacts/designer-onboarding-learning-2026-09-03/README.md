# Designer Portal Onboarding & Learning 2026-09-03

## Purpose

A persona-team proposal for the designer portal's onboarding and learning experience. Prepared 2026-09-03 as a brief pack + three persona proposals (documentation writer, customer-success lead, software-training expert) + their critiques + synthesis, for team input before an execution plan.

Learner persona: a growing design studio's owner and her first hire (Leah's studio, from `docs/vision/VISION.md` §2).
