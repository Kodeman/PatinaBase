# Designer-portal screens — briefing pack (captured 2026-09-03)

Local designer portal (`pnpm --filter @patina/designer-portal dev`, :3000) against the local Supabase stack (127.0.0.1:54321), signed in as the seeded studio owner `designer@patina.dev` ("Leah Hartwell"). Viewport 1440x900, light scheme, device scale 1.

## How they were taken

- Chrome (Claude-in-Chrome) was tried first; its window was stuck at a 1028px-wide viewport (page zoom on `localhost`; `resize_window` reported success but the window never changed, three attempts). 1028px is below the Studio Drawer's `min-[1180px]` breakpoint (`apps/designer-portal/src/components/document/studio-drawer.tsx`), so the desktop drawer never rendered there. Fell back to the Playwright scripts in this folder — `shoot.mjs` (main run), `shoot2.mjs` (help panel, Ledgers popover → Orders, spine dumps), `shoot3.mjs` (shot 06 under the flag override, see below). Run from `apps/designer-portal` with `node <script>`.
- Shot 06 required the `studio-workspaces` flag: the Account sheet's Studio page (`account-sheet.tsx`, `useFeatureFlag('studio-workspaces')`) is absent when the flag is off, and PostHog flags fail closed in dev. The dev server was restarted with `NEXT_PUBLIC_FLAG_OVERRIDES='studio-workspaces:true'` for `shoot3.mjs` and is **still running with that override** (PID in `DEVSERVER.pid`; first-run log in `devserver-run1.log`). Every other shot was taken before the restart, flag off.
- Compression: `sips -Z 1600`; anything over 400 KB re-encoded as JPEG 80 (only `01-signin` needed it).
- Dev-only chrome visible in every shot: the black "N" badge bottom-left is the Next.js dev-tools portal (`<nextjs-portal>`), the palm-tree circle bottom-right is the TanStack Query devtools button (`button.tsqd-open-btn`, aria "Open Tanstack query devtools"). Neither is Patina UI; crop or ignore.
- Verbatim label dumps used for `../nav-labels.md`: `labels.json`, `labels2.json`, `labels3.json`, `labels4.json`.
