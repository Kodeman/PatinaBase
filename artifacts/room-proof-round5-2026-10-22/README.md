## Suggested review path

1. Open the room spread. Unfold the survey, concept rendering and north-wall drawing.
2. In Drawings, compare revision B with C. Open LR-36, then use “Return to room design”.
3. Save an unsent drawing-set draft for Sam. It freezes A-101/B and A-201/C.
4. In Site & team, read OBS-07 and its illustrative attachment. Record a studio follow-up with “Request a drawing revision”.
5. Open the drawing and “File sample revision D”. Return to the saved set draft: it still contains C, and the discrepancy is visible.
6. Preview Sam’s Field copy. Record a sample observation, then return to the studio to review it. His older drawing set and the fabrication hold remain intact.
7. Review the existing item decisions and FF&E/purchasing views. Leave founder notes in the presentation and download Markdown.

All sample effects are local to this browser. No real send, upload, signature, payment, contractor grant or order is made. This is an HTML design proposal, not a production portal change. One living-room design thread is illustrated deeply; the other rooms retain their working FF&E schedules.

