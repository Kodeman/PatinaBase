# The Room Proof — design plan

The rejected proposal treated the room as a static cover and the job as a timeline. This proposal makes the room composition the entry into actual work. A furnishing has one identity across its position in the room, its material proof, and its maker instruction.

## Palette and type

- Document paper: #FCFAF6
- Warm stock: #E8E3DB
- Charcoal ink: #2C2926
- Quiet ink: #65594E
- Annotation blue: #355267
- Agreed state: #3E5145

Retain Patina's Playfair Display, Inter, and selective DM Mono. Change their scale, placement, and relationship to imagery. Type identifies the room and guides work; mono references point to actual objects rather than decorating every label.

## New architecture

```
Room                 Piece proof               Maker folio
scene + object index → object + finish evidence → exact specification
        same object identity, decisions, and document context
```

Room uses an expansive annotated image and an authored working margin. Piece proof changes the composition so the object and material alternatives dominate. Maker folio becomes a revisioned specification document. Core transitions happen in place, not inside a generic card modal. A text index duplicates spatial references for keyboard, mobile, and precision.

The founder presentation is a continuous editorial argument with a view explorer, outside-reference plates, an explicit inheritance from the original portal, and a local review form. It is newly authored rather than another copy of the prior five-slide shell.

## Review against the brief

The paper palette and serif type alone would reproduce the rejected pattern. They are retained because the user explicitly likes them, but the organizing unit changes from a timeline item to a room object. Different views deliberately have different layouts. There is no permanent lifestyle cover, repeating dashboard-card grid, or dark/light theme comparison.

One memorable interaction: select the chair in the room, open its material proof, record a sample choice, and see that same choice in the maker folio. The room is still recognizable while the type of work changes.

The supplied image is a generated, fictional room direction, not a verified furniture placement or a real client project. Finish swatches are illustrative. Precise production specifications would require real product records and verified samples.
