# Patina — The Room Proof

A new portal proposal for founder review · October 21, 2026

Open `index.html` to read the HTML presentation. Choose **Enter the prototype** to explore the working interface. The complete folder works locally without a build or external asset requests. Keep all files together; the accompanying ZIP contains the complete presentation.

## The idea

The room is the entry into the working document. Select an object in the room or its text index; inspect its materials in a dedicated proof; carry the client's choice into a maker folio. These are distinct arrangements for distinct work, connected by one object identity and one record.

The proposal retains the original designer portal's warm paper, Playfair/Inter typography, authored notes, fine ruling, and quiet document structure. It replaces the previous static lifestyle panel and milestone timeline with an actionable room, a material stage, and a specification document.

The prototype contains three connected views:

- **Room:** annotated room direction, object index, and a working margin for the selected furnishing.
- **Piece proof:** selected furnishing, material alternatives, studio preference, and client choice.
- **Maker folio:** numbered object specifications and a draft handoff. Client choice is separate from studio release.

The chair finish is the working sample decision. Other furnishings illustrate how object-linked inspection would extend across a room. Studio and Client preview demonstrate the intended visibility; they are not production authentication.

Founder review notes can be saved locally and downloaded as text. Nothing is sent to anyone. The prototype stores only local sample state and includes a reset control.

## Outside design research

The proposal is informed by outside references, not a collaboration with the named studios. Observations and Patina applications are distinguished in the presentation. Research date: October 21, 2026.

1. **MOHEIM / baqemono:** the selected object's scale, variant navigation, and the connection to specifications. Sources: [MOHEIM's own design interview](https://moheim.com/stories/moheims-website/), [SWING BIN product page](https://moheim.com/products/swing-bin/), [Awwwards entry](https://www.awwwards.com/sites/moheim).
2. **House of Honey / Réplica:** authored room identity and purposeful contrast between photography and utility navigation. Sources: [historical Awwwards entry](https://www.awwwards.com/sites/house-of-honey), [current project example](https://www.houseofhoney.com/spaces/a-study-in-expression). The current site differs from its historical award version; the presentation does not claim the current design received that award.
3. **Formafantasma:** a document index as a direct interface to meaningful content. Source: [the studio's site](https://formafantasma.com/). No Awwwards recognition is claimed for this reference.

Additional exploration included [Park's Awwwards entry](https://www.awwwards.com/sites/park), [Harvard Film Archive](https://harvardfilmarchive.org/) and [Hem](https://hem.com/en-us/). These were useful context; the three named references above directly inform the presentation.

The design interpretations are proposals, not measured usability findings. Daily studio use, dense procurement cases, physical-sample review, and real handoffs would need validation.
