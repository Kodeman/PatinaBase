Act I · The inventory03

Patina has learned to version everything except the drawings.

Five systems already in the house do a piece of this work. Each holds part of a plan room; none of them holds a plan room. Read the right column as a shopping list — it is the whole build.

The systemWhat it already hasWhat it lacks

Proposal supersede Supersede-on-send: issuing a new revision retires the old one atomically, and the retired one says so. bound to the proposal lifecycle · one document per event, never a set · no audience, no purpose, no re-issue to a subset

The punchline

Every part of the plan room already exists once, somewhere in the house. What has never existed is the sheet — the identity that outlives its files and holds one pointer saying which print is true.

Act II · The laws04

Six laws every direction obeys.

These are not the differences. They are the floor. A drawing surface that fails one of them is not a plan room — it is a folder with better manners.

Law one

One sheet, one identity.

A file is a print of a sheet. ID-401 is the sheet; Rev A, Rev B, and Rev C are prints that stack behind it. Uploading a file never mints a sheet.

Law two

The current set is the default truth.

Every surface — studio, client, token — opens on the current set. History is one gesture away and never the front door.

Law three

Nothing becomes current silently.

Every promotion crosses the Light Table and a human hand. Uploaded is not published; the machine proposes, the designer confirms.

Law four

An issue is a promise.

What was sent never changes. Correcting an issue means minting a new one that supersedes it — never rewriting the old. Inherited whole from the Spec Book.

Law five

Superseded paper says so on its face.

The stamp is on the paper wherever the house hands it to you — the portal, the token view, and the download, which burns it in as it serves. The stored print never changes, so its checksum keeps standing.

Law six

The PDF is the word given; the DWG is the hand that wrote it.

We version the word. The source file may ride along as an attachment — never synced, never parsed, never promised.

Why law six is a law and not a preference

Two-way CAD sync is the graveyard of this category. Procore built it, shipped it, and killed it in September 2022 — the failure mode is not a bug but a promise: once a platform claims to understand the drawing file, every mis-parse becomes the platform’s liability, on a job site, against a saw. Patina versions the plot, which is what the trade builds from anyway.

Act II · The model05

The nouns, over the Whitlock set.

Eight nouns, each one an extension of something already shipped. Nothing here is invented from nothing; the plan room is mostly a rearrangement of primitives the house already trusts.

The Sheet

Identity.

ID-401 · Millwork Elevations — Study. A number, a title, a discipline. Promotes today’s fragile client-side title-match into a server-side noun.

The Print

One file, one revision.

Rev A · 8 Jul, Rev B · 22 Jul, Rev C · 1 Aug. version_of hardened server-side; rev letters assigned at confirm, never parsed from a filename.

The Current Set

The pointer.

A server-held current_print_id per sheet. The seven pointers read together are the current set, and they are the default view everywhere.

The Light Table

Uploaded ≠ published.

Split, propose, confirm. The staging surface where a drop becomes prints, and where the whole set flips in one transaction or not at all.

The Issue

A named, dated version set.

“Production Set — 4 Aug 2026.” The spec_book_revisions grammar verbatim: immutable ledger, snapshots, sha256, drift detection.

The Transmittal

Who, what, when, for what purpose.

Immutable. document_shares grows a plan_set kind; the guest route is /plans/[token], no account, no new auth surface.

States

Draft → Shared → Issued → Superseded.

Four words on the face of every print. The model can retire client_visible as a separate toggle and derive client visibility from “at least Shared” — question three asks whether it should.

Notes

They ride the sheet.

An anchored note attaches to ID-401, not to Rev B. It promotes forward wearing “carried from Rev B — confirm placement.”

Two doors this model could open

Room Files could register as system-authored sheets — the scanner would become the first thing in Patina that publishes to the plan room, without a designer ever naming a file. And Spec Book issues could appear as lines of record in one project-wide transmittal ledger, so “what has this trade been sent” had a single answer instead of two. Neither is settled here: question one on slide 16 asks the first of them, and the second waits on it.

Act IV · The ladder11

How a plot gets from Nell’s machine into the plan room.

Three rungs, in the order they can be built. Each one shortens the walk between AutoCAD and the Light Table; none of them changes what happens once the pages arrive. The table still proposes, and Nell still confirms.

The drop.

Cost: zero on her side. This is the rung that closes the wound.

The grave we walk past

Procore built true two-way drawing sync and killed it in September 2022 — Procore Sync, the two-way desktop client, was retired that month, and its replacement, Procore Drive, is bulk transfer rather than sync. Every rung above moves the plot — the PDF, the word given. Law six holds all the way up the ladder: the DWG may ride along as source, unread, unparsed, unsynced. The moment a platform promises to understand the CAD file, every mis-parse becomes its liability against somebody’s saw.

Caption  Every rung feeds the same Light Table. The ladder changes how prints arrive — never what confirms them. A studio on rung one and a studio on rung three file identical sheets into identical sets, and both of them press the same confirm.

Act V · Direction A12

A · The Deep Folio — one paper, deeper pockets.

No new room. The folio unfold inside /doc/[id] grows a Drawings shelf; chips become sheet chips with rev letters on their faces; the shelf’s face is the current set. The Light Table opens as an overlay when a drawing-shaped file lands, and issuing happens from the shelf. Ladder rung one only.

What it foregrounds

R21’s one-surface law, kept absolute.

Days after the R21 dissolve spent itself removing surfaces, this adds none. The drawings live where every other paper on the job already lives.

Signature device

The shelf line.

“The folio · 12 papers  ·  The set · 7 sheets · current as of 4 Aug · 2 issues.” One line that makes the set a first-class citizen of the paper.

What it risks

A low ceiling, visible from here.

A 24-sheet job inside a letterhead unfold. The log, the stacks, and the transmittal ledger have nowhere to breathe, and a chip is not a sheet.

Act V · Direction B13

B · The Plan Room — the drawings get a room; the paper keeps its calm.

A named room, reached from the paper. The project section of /doc/[id] carries a threshold band — “The plan room · 7 sheets · current as of 4 Aug · Boone holds Rev B” — that opens /doc/[id]/plans, where the drawing log, the Light Table, the sheet detail, and the issue ceremony all live at full size. The Folio stays for loose papers; a drawing-shaped upload to the folio offers “file this to the plan room?” Ladder rung one ships; the Print Tray is designed and drawn, not built.

What it foregrounds

The object at its true size.

A sheet set is the one artifact in Patina that cannot live as a chip. It has pages, revisions, audiences, and a history — and every one of those needs room to be read.

Signature device

The threshold.

The room opens like a flat-file drawer and closes again. It is a band on the paper, not a tab in a nav — you are always somewhere in the job, never in a second application.

What it risks

A second surface, days after the dissolve.

R21 spent itself removing surfaces eight days ago. This adds one back. The discipline that saves it is that the room must stay a drawer off the paper — never a second desk.

What it foregrounds

Friction.

Close · The ruling16

What the deck would do.

A recommendation, the parts worth taking from the directions we do not build, and the three questions that decide it.

The deck’s recommendation

Build B · The Plan Room.

The wound is ownership of the pointer, not upload friction. Nell already uploads — twice, on the first of August. Abel cut from Rev B because nothing owned the word current and nothing recorded the send.

The drop plus the Light Table closes that entire loop with zero installs. The tray is an amplifier for a habit the room must first create; building it in v1 stakes a new desktop platform on a surface with no users yet, over Procore’s grave.

And A cannot carry it. A 24-sheet job, a three-print stack, a drawing log, and a transmittal ledger do not fit inside a letterhead unfold — the ceiling is visible from the first mock.

Steal these, whatever wins

Take A’s shelf line as the paper-side face of the room — the set should always be legible from the paper, even when the room is closed.

Take C’s Print Tray and draw it into the roadmap as the very next cut. Its outbox discipline is already proven on iOS; it does not need inventing, only porting.

Take the Spec Book’s issue law whole. Immutable ledger, snapshots, sha256, audiences, drift detection — do not re-litigate a grammar that already ships.

Three questions to shape the ruling
1

Does the Plan Room absorb the Room Files?

The scanner already produces versioned, checksummed drawing sets. If they register as system-authored sheets, scan output and Nell’s plots share one log and one current set. If not, the project carries two drawing surfaces from day one, and the second one is the one nobody was told about.

2

Can a transmittal ever be recalled?

Two honest answers. Reissue-plus-notice — the record stands, amended, and the trade always sees what he was sent. Or true token revoke — the record admits erasure, and a link can go dark. The answer is the trust story we tell trades, and it should be chosen deliberately rather than fallen into.

3

Does the current set gate the client absolutely?

Is Margot’s portal only ever the issued set — retiring client_visible as an independent toggle inside the plan room — or does Shared survive as a middle state? One is calmer; the other is the toggle designers already know how to reach for.

Close · The first cut17

The first cut, and what it deliberately leaves out.

Each line names the primitive it extends, because that is the whole argument for the timeline: almost nothing here is new machinery.

Ships first
  • The sheet, and server-side stacking. A sheets table; version_of hardened behind an RPC with a single-chain-head trigger; rev letters assigned at confirm, never parsed.
  • The current-set pointer. sheets.current_print_id, server-held, flipped atomically for a whole set.
  • The Light Table. Client-side PDF split and a sheet-number parse off the text layer; proposal only, human confirm, no OCR.
  • The Plan Room view. The drawing log, the stacks, and SUPERSEDED stamps burned in at serve time — never rewriting the stored print.
  • Client /documents, reborn as the current set. Which closes the proposal-anchor gap in passing: today a proposal-anchored document marked client_visible never reaches the client hub, because the hub queries by project_id alone.
  • The Issue and the Transmittal. document_shares grows a plan_set kind; a transmittals ledger — issue, recipient, purpose, sent_at, opened_at; guest route /plans/[token].
Later, in rough order
  • Set-flip notifications, and the amber “holds Rev B” digest.
  • The Print Tray — ladder rung two, the iOS outbox ported to the desktop.
  • Red/blue compare overlay. Needs a raster pass the folio pipeline does not have today.
  • Title-block OCR, for studios whose plots arrive without a text layer.
  • Drawn markups with promote-forward. v1 carries anchored note threads only.
  • In-CAD Publish to Patina — ladder rung three.
Never
  • DWG parsing. The source file may ride along as an attachment, unread.
  • Bidirectional sync. Procore’s grave, and we walk past it on purpose.
  • Rewriting a stored print. What was sent never changes; a correction is a new issue that supersedes the old one. The supersede stamp is added on the way out, never on the way in.
Close · Colophon18

What happens next, and what has not happened.

Three quiet paragraphs, so nobody has to guess how much of this is real.

If the ruling lands

The first cut is weeks, not months — every noun in the model extends a primitive that already ships. The room goes behind a feature flag; the folio keeps working exactly as it does today, and a job with no drawings never sees a threshold.

The one genuinely new thing is the pointer, and the pointer is a column.

What this deck is not

Nothing is built. No migration exists. No component was written, no route touched, no flag created. The Whitlock residence is fictional and lives only in this file.

Three directions are drawings. Two of them will not survive the ruling, and that is the point of drawing three.

Colophon

Self-contained — one file, no external fonts, scripts, images, or requests. No shadows anywhere; depth is flat paper offsets, rules, and value contrast. Every picture is drawn in CSS.
