## Not verified

The ten named C4/C6 mutation RPCs have an actor × active/inactive SQLSTATE matrix. The real Storage API byte test uses seeded owner/admin and seven refused JWT/anon readers; it does **not** create linked household signer, member, guest or removed-member identities for HTTP, and does not bind the uploaded bytes to an intake. An HTTP POST to the running local `service-acceptance-paper-hash` edge runtime with the seeded owner's signed JWT and a deliberately absent intake returned `403 {"code":"forbidden"}`. This establishes that the handler refused an unlisted intake, **not** that it downloaded or stamped any bytes. Actual edge-handler byte download/stamp and client evidence export HTTP API remain unverified. X03's owned-port real two-session suites now cover invoice claim, grouped PO, client-court selection decision, print issue and C6 completion/condition, each twice. The client-court choice fixture has no edition ID, so an edition-linked selection conflict and browser editor recovery remain unverified; full X03 remains weak. Full X09 mutation-family audit/invalidation and cross-key hash conflicts remain weak. No browser, native or production execution. No product defect is inferred from these gaps.
