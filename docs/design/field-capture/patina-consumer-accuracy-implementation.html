Consumer accuracy · implementation deck

A room your designer can trust.

Patina quietly gathers the evidence. A homeowner simply walks the room, checks one measurement if they want, and keeps moving.

calm capture×defensible result=useful room
RoomPlan · posed photos
mesh · depth · one known span

Open with the outcome, not the scanner. The consumer promise is a room a designer can work from—not a measurement instrument in the homeowner’s hands.

This is an implementation proposal. It does not claim the proposed flow is built or device-verified.

The product move

Preserve the evidence. Remove the ceremony.

Field Capture exposes the survey. Consumer Patina should expose only the next helpful action.

Field

Proves the room

  • Instrumented setup and explicit device checks
  • Multiple anchors and field QA scorecards
  • Technical exceptions for a trained operator
  • Detailed geometry and tolerance review
Consumer

Assures the homeowner

  • Automatic readiness before the walk begins
  • One optional long measurement, never a gate
  • Plain recovery guidance in the moment
  • Numbers appear only with the processed result

The accuracy architecture stays shared. The experience contract changes. Field users see instrumentation because they can act on it; homeowners see coverage, recovery, and confidence.

Production exclusion · no Coolify · no homelab · no retired host or tunnel

The approved topology is Supabase for Storage and Postgres, the existing audited queue contract, and Cloudflare for the processing worker. This intentionally supersedes the retired infrastructure named in older Field material.

Phased implementation

Ship in layers. Earn each claim.

Phase 0 · contract

Phase 1 · iOS

Make capture calm

Motion keyframes, surface coverage, one anchor entry, post-scan recovery, consumer copy.

Gate · LiDAR device, 10-minute thermal run, missed-wall recovery
Phase 2 · result

Correct and report

Cloudflare worker, anchor-adjusted parametric geometry, residual report, Room View states.

Gate · golden rooms + Storage/DB confirmation + product review
Later · research

Increase fidelity

Pose refinement, dense fusion, and splat training only after the parametric path is dependable.

Gate · measured gain, device cost, privacy and operations review

Phase 1 can improve collection without promising numeric accuracy. Phase 2 earns the tolerance receipt. Dense reconstruction is not on the critical path.

Failure behavior + device boundaries

Tell the truth. Preserve the room.

Missed wall

Show one recovery route. If skipped, save and mark the affected surface as lower confidence.

Low light / speed

Give an exact correction during capture; select the sharpest posed frame already on the shared clock.

Thermal pressure

Reduce optional depth sampling, keep the parametric capture, and explain only if action is required.

Measure skipped

Save normally. Verification remains “standard capture”; no shame language and no hidden gate.

Upload interrupted

Hold the bundle locally, resume only missing artifacts, and confirm Storage before reporting success.

Privacy

Explain photos and room geometry before capture. Keep service-role server-side and every processing transition auditable.

Non-LiDAR support is a separate product route, not degraded accuracy mode. The data can still help a designer, but the language must not imply measured geometry.
