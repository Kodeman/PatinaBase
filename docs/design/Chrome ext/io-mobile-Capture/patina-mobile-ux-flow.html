Patina · Tool T-03 · iOS UX flow & screen specification

Capture in the room.

Half of a project is sourced where there’s no URL — showrooms, markets, fabric houses, salvage yards. This is the field-capture app, mapped end to end: a camera-first iOS tool that turns a thing in front of you into a structured, located, synced specimen — every screen, gesture, and state.

32 screen states·8 flows·1 capture lifecycle·iOS · v0.1 for validation

How to read this · No. 01

Camera-first, by design.

This tool inverts the usual app: there’s no home screen to pass through — it opens straight to a live viewfinder, because in a showroom the moment is now. The same node and state colours as the rest of Patina carry through: verdigris is value & success, brass a decision or recognised data, rust friction or an edge.

Entry point

How capture begins — icon, Action Button, Control Center, Share Sheet, Siri.

Screen state

A distinct full-screen view the user sees and acts on.

Decision

A branch — capture mode, data quality, or a user choice.

Success / terminal

A specimen reaches the library, the inbox, or the offline queue.

Edge / fallback

Low light, unreadable tags, denied permissions, no signal — all handled.

Viewfinder anatomy · the home screen
Anatomyreference
The viewfinder, labelled

The app’s home is a live camera. Five regions sit in the thumb’s reach, nothing buried in menus:

  • Venue chipAuto-stamped location — “High Point · Showroom 214” — so every capture carries where it came from (F-08).
  • Framing guidesA reticle for square, level captures; the only “chrome” over the scene.
  • Mode selectorPhoto · Tag · Measure · Scan — the four ways to read a thing, one swipe apart.
  • ShutterTap for one frame, hold for a multi-shot specimen (F-01, F-02). Light haptic on press.
  • Session trayA running count of this visit’s captures; swipe up to review them all.
Interaction principles

Camera-first launch · one-handed reach · capture never blocks on network · every permission asked just-in-time, with its reason · haptics confirm, motion respects Reduce Motion, every control carries a VoiceOver label.

Flow 0 · First run & permissions

Earn each permission, just in time.

Flow 4 · Resilience & edges

Showrooms are dim. Basements have no signal.

The field is hostile to capture: low light, glare on a tag, an older device, a dead permission, no bars in a warehouse. Each has a designed path that keeps the find. The rule holds: a capture never fails, and never blocks on the network.

Capture lifecycle · No. 11

Whatever the entry or mode, a capture follows one lifecycle: it goes live, freezes to a specimen, loops while the designer enriches it, may rest in a session, gets routed, and resolves to saved, inboxed, or queued. This is the model the screens implement.
