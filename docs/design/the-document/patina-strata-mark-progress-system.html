Patina · Brand System · R15 + the gradient fade

The Strata Mark,
as a measure of time

The mark was always three layers of accumulated time. This spec gives those layers a job: each line is a movement of an engagement, each its own color fading back through history, and the mark fills as the work moves from first conversation to final care. One device now answers, everywhere it appears, the quietest question a designer carries — how far along is this?

The concept

Three lines, three movements

An engagement moves through seven sections (Brief → Care), but it lives in three movements — and the mark has exactly three lines. Line one is the oldest layer, fully present; line three is the newest, reaching forward, rendered softer in the canonical gradient fade. A line fills as its movement completes; the active line breathes.

Procurement, install, and care. The layer still being added — softest in the fade, reaching toward the present.

Why this mapping and not a seven-segment bar: the mark is a brand device first. It must read as Patina at a glance and reveal progress on a second look — never become a progress bar wearing a logo. Three movements keep it honest; the fractional fill within a movement (a half-filled active line) carries the finer grain.

The states

Static · Loading · Progress · Live

1 · Static — the brand mark

At rest, with no engagement to measure, the mark is simply the logo: all three lines present at their canonical widths, the third faded. This is the wordmark's companion, the watermark, the section divider.

Static · full presence
Three sizes, one mark. The fade is structural: line 3 at ~55% opacity regardless of size.
Static · on charcoal
On dark grounds the colored fills carry; the track disappears.

2 · Loading — the breath and the sweep

Two distinct loading behaviors for two distinct moments. The breath (R15's single sanctioned ambient motion) is for an active, present thing — the spine marker of the document in hand. The sweep is for indeterminate work — a scan running, a save in flight, the Aesthete thinking — where the lines fill bottom-toward-top and reset, time accumulating and beginning again.

The breath · active marker
~3s opacity swell, staggered per line. Used on exactly one element at a time. prefers-reduced-motion stills it to a steady glow.
The sweep · indeterminate loading
Lines fill in sequence then fade and restart — the Whisper Bar's quiet cousin. Replaces spinners everywhere.

When progress is known, the mark holds a fixed fill. Below: the same mark at five points in an engagement, frozen. The colored portion is real completion; the ghost track is what's still to come.

The specification

Build contract

Geometry (brand canon, preserved)

LineWidthHeightOpacity (track)MovementFill color
1 · top100%100%fullShapingMocha #5C4A3C

*In this implementation all lines share a height for crispness at small sizes; the brand's decreasing-height ratio is available via per-line height vars when the mark is rendered large (wordmark lockup, hero). Width ratios and the opacity fade are always honored.

The fill API

One CSS custom property per line, --f from 0 to 1, drives the colored portion. Unfilled = ghost track. The component reads engagement state and sets three values:

/* per-line fill from engagement stage */
.strata i:nth-child(1) { --f: var(--shaping-fill);    /* Brief→Direction */
.strata i:nth-child(2) { --f: var(--commitment-fill); /* 0 or 1 — signed is binary */
.strata i:nth-child(3) { --f: var(--delivery-fill);   /* Project→Care */

/* stage → fill triples (the scrubber's real values) */
Brief        → [0.15, 0, 0]      Signed       → [1, 1, 0]
Discovery    → [0.5,  0, 0]      Procurement  → [1, 1, 0.4]
Direction    → [1,    0, 0]      Install      → [1, 1, 0.7]
Proposal     → [1,  0.5, 0]      Care         → [1, 1, 1]

The three behavior classes

ClassWhenMotion
(none) + fill varsDeterminate progress; static brand mark (fill=1)Fill transitions at .6s ease on value change; otherwise still
.breathingThe single active element (spine marker of the held document)~3s opacity swell, staggered; one at a time; reduced-motion → steady glow
.sweepingIndeterminate work (scan, save, Aesthete thinking)Lines fill in sequence, set fades and restarts (~2.2s); reduced-motion → static partial

Rules of use

DoDon't
CountAlways three linesNever add or drop lines to mean more stages
MotionOne breathing mark per viewNever breathe a mark on the Desk — nothing on the Desk moves
FadeLine 3 always softer (the gradient)Never equalize the three — the fade is the brand
ColorMovement hues for fill; ghost track for unfilledNever use stamp colors (sage/terracotta) in the mark
HonestyFill reflects real stageNever animate fill as decoration on a static brand mark

Lineage. This formalizes R15 (the Strata Mark as a progress device, line 1 = Shaping, line 2 = Commitment at signing, line 3 = Delivery) and the breath (R15's single sanctioned ambient motion). The per-line gradient coloring extends the brand's documented gradient-fade — each line now its own movement hue rather than a single color at decreasing opacity, while preserving the canonical 100/80/60 width ratios and the soft third line. For the log: if Kody blesses the three-hue treatment over the original single-hue fade, that's a one-line ruling extending R15; the fill API and the .sweeping indeterminate loader are new and would log as the component's build contract.
