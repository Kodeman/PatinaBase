Executive summary

Across 200 mapped /portal capabilities: 28 full · 55 partial · 14 transformed · 103 absent in /desk today — plus 21 Document-native capabilities with no /portal analog.

The shape explains itself: /portal is a create/edit surface; /desk is a read + act-on-needs surface. The Document covers the daily operating loop extremely well — pick up work, resolve a decision, send a PO, log inspection, chase a receivable, log time, teach a product — but covers authoring / CRUD and discovery / list views thinly or not at all. The ⌘K command bar only routes to documents + 5 books + Desk + Engine, never to an arbitrary old zone, so anything not folded into those is reachable only by falling back to /portal.

Biggest absent clusters: Proposal authoring (20), CRM / Communications (17 — the People book is a literal placeholder), Billing / invoicing depth (13), Decision composition (11), account / platform settings (11).
Strongest coverage: Library / Teaching (16 full) and Procurement core (PO send, Order Assistant, receiving inspection reused 1:1).

The Document at a glance what /desk offers

  • Desk (/desk) — two populations only: needs-your-hand FolderCards (one need-line each) + in-motion chips. No list / filter / dashboard.
  • Document (/doc/[id]) — full-bleed paper: a 7-marker spine, letterhead, settled-bar history, the one active section (Brief → Discovery → Direction → Proposal → Project → Install → Care), the margin rail (5 kinds), the Account band (R26).
  • Studio Drawer books (⌘K / bottom strip): Library (a walk-in Room — 3-layer shelves + Engine ask + capture + teach), Orders (Ledger / Week / Receiving / Vendors-thread), Accounts (Ledger / Receivables / Earnings), Hours (time), and People → placeholder, not built.
  • Compose (/compose) — anti-wizard “compose a catalog piece” (R40). Aesthete Engine — librarian bar + “Ask the Engine” in ⌘K; stateless.
  • Cross-cutting: Strata Mark progress device, ink Stamps, one-act-many-surfaces propagation, client mirror, document-anchored time, interruption settings.
