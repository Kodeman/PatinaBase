# Feature Gap Matrix — `/portal` (legacy zones) vs `/desk` (The Document)

_Designer Portal · generated 2026-06-14 · source-verified by a 19-agent codebase sweep_

> **Companion artifact:** `portal-vs-desk-feature-gap-matrix.html` (same data, presentable deck).

## Executive summary

Across **200 mapped `/portal` capabilities**: **28 FULL · 55 PARTIAL · 14 TRANSFORMED · 103 ABSENT** in `/desk` today — plus **21 Document-native** capabilities with no `/portal` analog.

**The shape explains itself: `/portal` is a create/edit surface; `/desk` is a read + act-on-needs surface.** The Document covers the daily operating loop extremely well (pick up work, resolve a decision, send a PO, log inspection, chase a receivable, log time, teach a product) but covers **authoring / CRUD and discovery / list views** thinly or not at all. The ⌘K command bar only routes to *documents + 5 books + Desk + Engine* — never to an arbitrary old zone — so anything not folded into those is reachable only by falling back to `/portal`.

**Biggest absent clusters:** Proposal authoring (20), CRM / Communications (17 — the **People book is a literal placeholder**), Billing / invoicing depth (13), Decision composition (11), account / platform settings (11). **Strongest coverage:** Library / Teaching (16 FULL) and Procurement core (PO send, Order Assistant, receiving inspection reused 1:1).

**Roadmap priority counts** (PARTIAL + ABSENT rows only): **P0 53 · P1 87 · P2 18**.

## The Document at a glance (what `/desk` offers today)

- **Desk** (`/desk`) — two populations only: needs-your-hand **FolderCards** (one need-line each) + **in-motion chips**. No list / filter / dashboard. (`partitionDesk()`)
- **Document** (`/doc/[id]`) — full-bleed paper: a 7-marker **spine**, letterhead, settled-bar history, the one active section (Brief → Discovery → Direction → Proposal → Project → Install → Care), the **margin rail** (5 kinds), and the Account band (R26).
- **Studio Drawer books** (⌘K / bottom strip): **Library** (a walk-in Room — 3-layer shelves + Engine ask + capture + teach), **Orders** (Ledger / Week / Receiving / Vendors-thread), **Accounts** (Ledger / Receivables / Earnings), **Hours** (time), and **People → placeholder, not built.**
- **Compose** (`/compose`) — anti-wizard “compose a catalog piece” (R40).
- **Aesthete Engine** — librarian bar (Library) + “Ask the Engine” in ⌘K; stateless, no thread (DECISIONS I30).
- Cross-cutting: Strata Mark progress device, ink Stamps, one-act-many-surfaces propagation, client mirror, document-anchored time, interruption settings.

## Roadmap — what to close next

### P0 — Parity blockers (core engagement loop not completable in `/desk`)

1. **Proposal authoring** — the single largest gap (20 absent). Bring compose into the Document: editable Direction/Proposal section, scope builder as a Room/sheet, send via a letterhead instrument. *Today: every proposal is built in `/portal`.*
1. **Decision composition** — create/edit/publish a new decision from a project (a “new decision” margin action/sheet). *Override / nudge / extend are already FULL.*
1. **Project lifecycle** — activation (from a signed proposal in-document), edit metadata / phase estimates (letterhead instruments), complete / close-out (a Care-section act).
1. **CRM “People” book** — currently a placeholder. Build the Studio Drawer sheet: client directory + profile/relationship + threads; surface client-initiated messaging.
1. **Invoicing depth** — record-payment, void, resend, print/PDF, ad-hoc / FF&E / time line kinds, unbilled-time pull-through. Extend `InvoiceBody` + Accounts Ledger beyond milestone → Generate.
1. **Vendor directory + create** — discover / add / save vendors. Add a Vendors directory page to the Orders book (today only the brief-thread for *existing* vendors exists).
