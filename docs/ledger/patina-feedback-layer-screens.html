  1. 1Bucket. Single-select, required. Four fixed options, each with its own color + glyph. Submit is disabled until one is chosen.
  2. 2Note. Free text, encouraged but optional — a one-tap "Working" with no words is still valid signal. Placeholder adapts to the bucket.
  3. 3Context. Auto-captured, shown read-only. She never types where she is.
  4. 4Screenshot. Optional, default on. Captures the screen as it was when the sheet opened — not the sheet.
  5. 5Weight. Optional priority (Low / Med / High). Priority is her call, never an inferred guess.

Screen 09

Optional layers

Phase 3+ affordances layered on top of the button — each independently shippable.

Shortcut

Keyboard drop. A hotkey (⌘⇧F) opens the sheet from anywhere — hands on keys.

Voice

Quick-jot. A few words or a voice memo, for when typing is too slow.

Nudge

Gentle prompt. If she's been quiet a while, a light, dismissible ask of the four questions.

Weight

Weight forward. Surface priority more prominently once there's volume to sort.

  1. 1Additive only. The persistent button stays the primary path; these never replace it.
  2. 2Independently shippable. Add any one when it earns its place — no dependencies between them.
  3. 3Same store. Every path writes the same note shape into the same table.
