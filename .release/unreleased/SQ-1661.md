The focal editor no longer shows a cover the media worker does not cut. When a white ground, a subject box or the size floor rules a crop out, that frame shows no picture and says which crop those screens draw instead, for example "Phones show the wide cover for this photograph." A white-ground clipping is cut only as a pair and a piece, so neither cover frame is offered for it. The band's cover thumbnail shows the window of the crop the client page's desktop draws, at that crop's own shape and within 120px tall, so a 3:2 or tall cover is no longer squeezed into a 16:10 box. In the client mirror, captions are credited as the homeowner reads them, by the picture's attribution rather than the address it was fetched from. With makers off, a maker or upload picture names the studio, and an override cannot bring the maker back. With makers on, an override wins. Other pictures keep their override either way. With makers off, the cover's description for screen readers is rebuilt from that caption, so it names no maker the caption hides. Source previews are signed in the bucket of the table the picture came from; a picture from an unknown table shows no preview.
