title: Document extraction keeps a paid answer through Files API cleanup
bump: patch
plugins: []
---
project-ffe-document-extract returns the model's answer as soon as it arrives and deletes the temporary Files API upload afterwards, best effort, within its own 10 s (kept alive by `EdgeRuntime.waitUntil`), so a slow delete can no longer turn a paid answer into a zero-cost retryable timeout under `callClaude`'s 120 s window; the upload and the model call now take that window's deadline signal.
