title: Claude calls end their reservation and model call inside one timeoutMs window
bump: patch
plugins: []
---
`callClaude` now runs the ledger reservation and the model call, SDK retry included, in one window that ends `timeoutMs` after the call starts: the SDK gets only the time the reservation left, and a model call still running at the window's end fails as a timeout. Settling keeps its own 5 s, so the composer always receives a paid answer and its cost (failed billed calls included) before its outer race, and `finish_client_edition` records them. For all six importers (aesthete-dna-draft, board-deck-import-resolve, client-edition-compose, companion-message, project-ffe-document-extract, sms-inbound via field-parse) the only behaviour change is that reservation time now counts inside `timeoutMs`; the composer's duplicate `callSignal` window in index.ts is removed.
