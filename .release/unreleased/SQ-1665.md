Add the client-edition-compose edge function: perception, hero pick, chapter words and voice lint through callClaude, with a strict answer validator, a facts allowlist (no project name, sheets, boards, studio identity, prices or notes) and plates-only publishing when the words are unchanged. Adds the perceive model role. (Folds SQ-1647; repaired after the SQ-1592 and SQ-1649 reviews.)

The composer:

- Pictures reach a model only as each plate's stored `piece` rendition (512 or 768 px WebP), read from the media worker and sent as base64. No address, path or file name is in a request. A picture the worker cannot serve is dropped alone. A response that declares more than 2 MB is canceled unread.
- Provenance comes from every `client_plate_requests` row for an asset, in any status, read in id-ordered pages until a short page and held to the first page's exact count. A read error, timeout or short count fails the edition before any picture is sent. Only upload, maker and concept pictures are sent, and scans and installed photographs once the privacy page is live. An asset with no row, or with any sheet, board or unknown source, is never sent. Sheets and concepts are never the hero.
- A flagged picture (`perceivedFlags`, or flagged in this run) is never the hero, held, or offered to the hero pick. A flag-only change now composes again, so an approved page's held pictures are re-checked. The frozen facts carry the flags this run recorded.
- Image rows keep `perceivedAlt`, except that while makers are hidden a maker or upload picture takes the alt built from its masked caption.
- A held choice must meet the held floor. Designer-framed pictures are perceived for flags and alt with a null frame. Model frames are sent on the recrop's 1e-4 grid.
- Unchanged is judged on the source hash and a fingerprint of every frozen render fact and the perceived flags. Plates-only compares the designer-corrected chapters (by key) and doorstep, without the notice. Call B sees the corrected words, and none of them when makers are hidden.
- One lint (canon, machinery words, and model or vendor attribution with the project's own names allowed) covers the words, alt text and the hero's why. An allowed name is blanked only as a whole name, so a piece called Gem does not hide Gemini. A judge that cannot answer twice leaves the deterministic headlines.
- One time budget for the whole invocation. Every claim, read, perception write, ledger call, model call and finalizer has a bounded window and an abort signal, and the finish has a reserved 10 s. One request is claimed at a time, only while an edition fits. A later claim that fails or throws ends the batch and keeps its outcomes and cost.
- finish_client_edition is tried for the draft twice, then as failed with the spend. Before each retry and after the last, the edition's status is read, so an answer lost after a write is reconciled. If no finish is confirmed, the run reports the edition id, the spend, and the recovery: the dispatcher's sweep fails the drafting edition when its lease lapses. Begin has already closed the request, so the project composes again on its next edition request.

`_shared/claude.ts`: `callClaude` takes an optional abort `signal`, which now also bounds the ledger reservation, and an optional `ledgerSignal` that bounds settling. A failed call whose error reported usage returns the settled `usd`. `LlmLedgerPort.reserve` and `settle` take an optional trailing signal, which `createLlmLedger` passes to the RPC. All of these changes are backward compatible.

media-worker: adds `GET /plates/{projectId}/{sha256}/piece-512.webp|piece-768.webp`. It requires the `PLATE_INGEST_SECRET` bearer, returns 401 or 404 with no body, and reads nothing outside that allowlist. A bucket read that throws answers 404, the same as a miss.

- The composer reads the existing `MEDIA_WORKER_URL` and `PLATE_INGEST_SECRET` function secrets.
